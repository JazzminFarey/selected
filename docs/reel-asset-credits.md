## Rebuilding

Set `REEL_SOURCES` to the folder containing the exact source files named above, then run `python scripts/reel/build.py` and `python scripts/reel/sound.py`. Requires FFmpeg and Pillow. Generated typography and layout frames are editorial compositions of the listed source assets. The timeline records each cut in 30fps frames; total 900 frames.
