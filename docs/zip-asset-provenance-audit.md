- Five of the nine existing social destinations have exact-URL, Zip-publisher evidence in public search indexes. These are **A with an access limitation**, not a frame-by-frame visual verification or a permission finding. Four destinations remain **D pending verification**.

A generic Zip homepage link establishes context, but cannot replace the evidence supplied by a campaign gallery. Decide explicitly between a text-led case pending sources, or retaining authentic assets after permission/provenance confirmation.

A file need not be visible in a page to remain available through a static-site asset URL.

Methods: repository-wide reference inventory; Git introduction/change history; SHA-256 duplicate grouping; image dimensions and available PNG/JPEG/EXIF metadata; visual inspection of all image compositions and side-by-side inspection of the covers; public web and image searches using exact campaign copy, campaign names, post IDs and full post URLs. Searches prioritised Zip's site/social channels, then campaign/agency sources and advertising press. Scrapers, anonymous viewers, Pinterest and unrelated reposts were not accepted as provenance.

**Access limits:** direct Instagram and Facebook retrieval returned disabled/throttled/error responses; some exact posts were nevertheless present in search indexes with publisher/title information. Indexed snippets sometimes include unrelated neighbouring posts, so only clearly attributable title/account information is used. No authenticated playback or public-image pixel comparison was possible for these social posts. TikTok retrieval was unavailable to the search tool. Searches did not establish matching original assets on TikTok, YouTube or a relevant agency/press page. Failure to find an indexed original is not proof that it was never published. This is a source audit, not a rights clearance, legal opinion or exhaustive archival search.

## Classification and match rules

| Class | Meaning used here |
|---|---|
| A | Exact public post/video URL found on a Zip-owned channel, or exact official asset established. A search-index-only finding is explicitly qualified. |
| B | Matching asset found in a credible agency, publication or other campaign source, not clearly Zip-owned. No asset met this threshold in this audit. |
| C | Public campaign/content family supported, but exact local asset not found. |
| D | Reliable provenance for the asset/post could not be established. |
| E | Evidence of modification/recreation or uncertainty about the displayed derivative. Does not, by itself, mean AI-generated. |

“Exact URL” for an embed means the existing destination is independently indexed; it does **not** authenticate a similarly named local poster. “Likely match” identifies a candidate to check, never permission to reproduce. Source owner/publisher is not a determination of every underlying photographer, creator, music, talent or other right.
